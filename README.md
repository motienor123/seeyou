# seeyou

A friend-group calendar app. Plan events together, share quick snaps, and see everything in a full-year calendar view.

**Live repo:** https://github.com/motienor123/seeyou

## Features

- Create friend groups with profile pictures
- Full-year calendar — click any day (or drag a range) to create an event
- Multi-day events (e.g. vacations) with range highlighting
- Per-event colors (8-color palette, auto-assigned)
- Seasonal calendar tints — winter, spring, summer, autumn
- Quick-snap camera tab — upload photos directly to any event
- Lock snaps until after the event is over (Snapchat-style)
- EN / LT language toggle (Lithuanian)
- All data stored in localStorage — no backend required

## Tech stack

- Next.js 16 · React 19 · TypeScript · Tailwind CSS v4
- No database — localStorage only

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
